\begin{exercice}[Modèles de mémoire]

  Étudiez le code du programme \texttt{concurrence.Volatile}.

  \begin{questions}

  \item Exécutez le programme.

  \item Que fait le mot-clé \texttt{volatile} ?
  \end{questions}

\end{exercice}
